# Phase 01: Foundations Review

## Goal

Understand what you already built, identify its flaws, formally analyze its
computational complexity, and fix the bugs before moving forward.

This phase is deliberately short. It is a **diagnostic**. If any part feels
unclear, stop and research before proceeding.

## Files in This Phase

| File | What It Covers |
|---|---|
| `01-code-audit.md` | Walk through each existing file. What works, what doesn't. |
| `02-big-o-of-current-code.md` | Formal complexity analysis of your existing SpatialMap, QuadTree, DataLogger. |
| `03-fix-bugs-first.md` | The two bugs in your code and how to fix them. |
| `GATE-00.md` | **Gate:** Verified fixes + you can explain Big-O of every function. |

## Hard Gate Requirement

Before moving to Phase 02, you must:

1. Fix the `None` crash in `main.py` and `main2.py`
2. Fix the speed calculation bug
3. Be able to state the Big-O of every function in every file
4. Answer the check-in questions in each file

Proceed to `01-code-audit.md` to begin.
